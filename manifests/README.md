# Manifests

- `tasks.jsonl`: index and hashes for every public task.
- `references.jsonl`: Dev rubric/reference selection and hashes.
- `browser_validation.jsonl`: per-task Dev validation results.
- `dev_validation_summary.json`: aggregate Dev validation status.
- `asset_provenance.jsonl`: asset identity, source, license, and hash.
- `asset_substitutions.json`: release-safe asset substitutions.
- `membership_evidence.json`: immutable membership evidence and limitations.
- `extended_augmentations.jsonl`: controlled replacements for source gaps.
- `recovered_tasks.jsonl`, `recovery_exclusions.json`,
  `unresolved_tasks.json`, `unresolved_contracts.json`: recovery disclosure.
- `robust_variants.jsonl`: Robust parentage and rewrite metadata.
- `files.sha256`: checksum for every packaged file except itself.
